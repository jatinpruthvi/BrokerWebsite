# Product Requirements (Non-normative)

> [ARCHITECTURE.md](../ARCHITECTURE.md) wins. Expands ARCH-PROD-001–006, ARCH-WEB-004–007, and ARCH-PHASE-001–004.

Property seekers discover Buy/Rent inventory by city/locality, evaluate media, price, area, freshness, broker and RERA provenance, save/compare, create alerts, and submit a first-party masked lead. Brokers join organizations, draft and validate listings, upload media resumably, submit for review, manage lifecycle, and receive auditable leads. Editorial/operations staff review claims, listings, RERA observations, page quality, and incidents.

Public home, intent, city, locality, curated-intent, project, property, broker, RERA, and guide pages expose useful server HTML. Mobile conventional search/filter controls are primary. Results provide stable cards, URL persistence, loading/error/empty recovery, and accessible list/map synchronization. Details prioritize decision facts before optional video/map/effects.

Inventory is licensed from partners, never copied from portals. Verification/RERA labels state scope, source, and last check. Leads collect minimum data and consent, preserve attribution/status, mask contacts, and resist abuse.

Saved/compare/alerts plus natural-language/vector search, dense maps, motion, smooth scroll, and 3D remain approved. Advanced capabilities activate only through ARCH-PHASE-004 while conventional search/list, static media, non-WebGL, and reduced-motion paths remain usable. Acceptance covers low-end Android/4G, WCAG 2.2 AA, visible status, recoverability, lifecycle correctness, privacy, and supported claims.
