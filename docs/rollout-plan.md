# Rollout Plan (Non-normative)

> [ARCHITECTURE.md](../ARCHITECTURE.md) wins. Expands ARCH-PHASE-001–004.

## Phase 1 — contract-ready foundation

Freeze canonical entities, v8 routes/index matrix, provenance, and lifecycle contracts. Establish server-first pages, design/accessibility, URL search, PostgreSQL deterministic search, broker/listing/media core, masked leads, auth baseline, CI, telemetry, backups, and Vercel/Railway/Cloudflare ownership. Advanced adapters may exist behind flags; contract-ready does not mean activated.

## Phase 2 — trustworthy activation

Expand qualified entity/intent pages and sitemap operations; activate only legally reviewed RERA sources; deliver saved/alert workflows, MapLibre clustering/viewport search, authority/editorial processes, freshness SLAs, incident/restore drills, and measured scaling.

## Phase 3 — gated sophistication

Evaluate vector/LLM search, external engine, deck.gl, GSAP/Lenis/R3F, and broader localization independently. Record owner, hypothesis, evaluation data/device matrix, accessibility/privacy/security review, performance/cost/relevance target, staged exposure, and rollback. Deterministic search, accessible list/map fallback, static hero, and ASCII routes remain.

Each phase exits only with E2E/accessibility/security/indexability evidence, dashboards/runbooks, migration/rollback proof, and no unsupported public claims.
