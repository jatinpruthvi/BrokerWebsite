# ADR 0001: Document authority and precedence

**Status:** Accepted

## Decision
`ARCHITECTURE.md` is the only normative source. Topic docs/ADRs explain it; archived originals preserve history. Architecture wins conflicts.

## Rationale
Nineteen overlapping revisions contain valuable details and contradictions. Stable ARCH IDs create one reviewable contract without destroying provenance. Decision changes update architecture and normally add a superseding ADR.
