# ADR 0002: Server-first public and interactive layers

**Status:** Accepted

## Decision
Render public facts, primary inventory, and links server-first; progressively add filters, maps, saves, media, and dashboards.

## Rationale
Users, crawlers, and low-capability devices receive a useful baseline while the premium application remains. Interactive failure cannot erase discovery. See ARCH-SEO-001 and ARCH-WEB-002/004.
